# IEEE Student Chapter Website
A modern, responsive full-stack website built for the IEEE LOSC chapter. Designed to deliver a seamless user experience while maintaining scalability and performance.

live link:- https://opticachapter.lnmiit.ac.in/

Techstack:
  Layer    | Tech                                           |
| -------- | ---------------------------------------------- |
| Frontend | HTML5, Tailwind CSS, Typescript                |
| Backend  | Node.js, Next.js Prisma  ORM, Docker,          |
| Database | PostgreSQL / MySQL                             |
| DevOps   | Vercel, GitHub                                 |

 Publicly accesable site (About, Team, Events, Event Reports, Contact) with admin-only dashboard for content management.

 ✨ Features
⚡ Fast load times and optimized rendering
📱 Fully responsive across devices
🎨 Clean, modern UI
🔄 Dynamic content handling
🧩 Modular and scalable codebase
